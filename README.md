# CRAVEHUB — Restaurant Management System

## Stack
- Frontend: HTML5, CSS3, Vanilla JavaScript
- Backend: Node.js + Express
- Database: MySQL
- SQL features: tables, foreign keys, view, function, stored procedures, trigger

## Setup
1. Install Node.js LTS and MySQL.
2. Open MySQL Workbench.
3. Open `db/restaurantdb.sql` and execute the complete script.
4. Open this project folder in VS Code terminal.
5. Run `npm install`.
6. Copy `.env.example` to `.env`.
7. Put your MySQL password in `.env`.
8. Run `npm start`.
9. Open `http://localhost:3000`.

## Demo features
- Restaurant landing page
- Category filters and search
- Cart and checkout
- Customer creation
- MySQL order creation
- Automatic stock reduction through trigger
- Admin dashboard with sales, orders, customers and menu count
- Add menu item from dashboard

## Important
This is a local full-stack project. For a truly public internet URL, deploy the Node server and MySQL database to a hosting provider after testing locally.
